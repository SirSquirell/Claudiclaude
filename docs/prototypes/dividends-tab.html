Dividends — a new tab, not a new product

Everything below is a layout proposal for the "2026-08-23 refinement" conversation — which of Simply Safe Dividends' KPIs are worth porting, and roughly where they'd sit next to what US-102–109 already scoped. Nothing here is built; read the feasibility note on each block.

Income by position

Share of annual dividend income, not share of value — the gap between the two is exactly where concentration hides. Fully buildable now: no Layer B, no external data, just this account's own dividend history per position. Click a slice: sector, then the positions inside it.

Dividend safety, by income

This is US-109's own scoring model (see dividend-safety-buckets.html for the full per-input breakdown) — repeated here to show where it sits next to the others. Click a bucket to filter the whole page — including the table below — to just those positions.

Income forecast

Projects this account's own observed per-position dividend growth forward — the same pattern US-33's Outlook already uses for total value (projectPortfolio), applied to income instead. Refuses below a stated minimum history, same as Outlook does for a horizon longer than the account's own data can support — no year here is a promise.

Holdings, dividend view

A dividend-scoped column set, not the general Positions table. Consistency is new: a small per-year bar per holding (paid/cut/flat) — cheap, from this account's own history, and the fastest way to see "this cut once" that a single score number hides. A special tag flags a one-off payment so it never quietly inflates a yield calculation (the same trap US-99 already names for a single large dividend in a short window). Click a row for why it scored what it scored — the same named-ingredient breakdown as dividend-safety-buckets.html, never a bare number with nothing behind it (US-108 AC3).

Not shown: Beta (needs US-98's benchmark price series — not built), P/E ratio and Qualified/Non-Qualified taxation (the latter is a US tax concept; this account is Dutch/EU, US-106 already covers the withholding side that actually applies here).
